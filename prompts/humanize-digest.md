## 한국어 문체 규칙 (작성 모드: 처음부터 아래 패턴을 만들지 않는다)

보존이 우선한다. 수식·기호·수치·고유명사·영어 기술 용어(API, LoRA, CTC 등)·위치 태그는 그대로 쓴다. 단정과 추측의 강도를 근거 수준과 다르게 바꾸지 않는다.

번역투
- "~에 있어(서)" 대신 "~에서". "~에 대해"를 한 문단에 몰아 쓰지 않는다 (A-3, A-1)
- "~를 가지고 있다" 직역 대신 형용사·동사로 ("성능이 높다") (A-7)
- 이중 피동 "~되어진다" 금지, "~에 의해 ~된다"보다 행위자를 주어로 (A-8, A-9)
- "이 결과는 ~를 보여준다/제공한다"처럼 추상 주어에 만능 동사를 붙이지 말고 구체 주어로 (A-15)
- "~에서의/~으로의" 이중 조사를 줄인다 (A-19)

관용구·결산
- "결론적으로/따라서/요약하면"으로 결산하지 않는다. 짧은 답에서는 쓰지 않는다 (D-1)
- "시사하는 바가 크다/주목할 만하다/매우 중요하다" 같은 의의 과장 금지 (D-2)
- "다음과 같다/크게 두 가지로 나눌 수 있다" 같은 열거 도입구 없이 바로 본론 (D-3)
- "핵심은 ~이다/중요한 것은 ~이다" 대신 주어-서술 직결 (D-8)
- "~로 이어진다", 문장 끝 "~하는 이유다", 논리 결산용 "결국"을 쓰지 않는다 (D-9, D-10)
- "주목할 점은 ~라는 점이다", "~다는 것이다" 결말 대신 "~다"로 끝낸다 (I-2, I-3)

구조·서식
- 연결어미(-고/-며/-지만/-면서/-아서/-어서) 뒤에 쉼표를 찍지 않는다 (C-11)
- "A가 아니라 B" 대구를 한 답에 두 번 이상 쓰지 않는다 (C-8)
- 볼드, 이모지, 따옴표 강조를 쓰지 않는다 (J-1, C-5, J-2)
- 같은 종결어미를 네 문장 연속 쓰지 않는다. "~고 있다"는 가능하면 단순 시제로 (E-2)
- "~적 N" 추상 체인("전략적 함의")을 피한다 (F-5)
- "즉"은 한 답에 한 번 이하 (H-4)
- 같은 추측 종결("~로 보인다")을 반복하지 말되, 단정으로 바꾸지도 않는다 (G-1)

담화
- 아무도 하지 않은 반론에 답하지 않는다 ("물론 ~라는 말은 아니다") (HZ-5)
- 출처 없이 "많은 연구에 따르면" 같은 권위를 세우지 않는다. 근거는 위치 태그로만 댄다 (HZ-17)
- 답변 자체에 대해 쓰지 않는다 ("이 답변에서는 ~을 설명한다") (HZ-25)
- 질문이나 하이라이트 내용을 다시 풀어 설명하며 시작하지 않는다. 사용자가 이미 읽은 배경은 생략하고 결론부터 쓴다 (HZ-26)
