# Zotero Claude Assist

PDF 논문을 깊게 읽기 위한 개인용 Zotero 플러그인입니다. 설계는 [`context.md`](context.md), 구현하면서 바꾼 점은 [`docs/decisions.md`](docs/decisions.md)에 있습니다.

| 기능          | 하는 일                                                                                        | 백엔드                 |
| ------------- | ---------------------------------------------------------------------------------------------- | ---------------------- |
| 문맥 번역     | PDF에서 선택한 문장을 앞뒤 문장과 함께 번역                                                    | Gemini API (무료 티어) |
| 컨텍스트 노트 | 논문마다 구조화된 분석 노트를 한 번 생성 (태그 `claude-context`)                               | Claude (`opus`)        |
| 메모 질문     | 하이라이트·그림 주석의 `@claude 질문`을 모아 한 번에 답하고 질문 노트(태그 `claude-qa`)에 기록 | Claude (`sonnet`)      |
| 채팅          | 논문 전체에 대한 대화. 필요하면 모델이 섹션 원문을 직접 읽음                                   | Claude (`sonnet`)      |

Claude는 로컬에 설치된 공식 `claude` CLI(Claude Code)를 실행해서만 씁니다. 로그인 토큰을 직접 읽거나 Agent SDK를 쓰지 않습니다 (`context.md` §3).

## 요구 사항

- macOS, Zotero 10 (10.0.9에서 테스트)
- Claude Code CLI 설치 및 로그인 (터미널에서 `claude` 실행 → `/login`)
- 문맥 번역을 쓰려면 Google AI Studio API 키 (결제 계정 연결 없이 무료 티어)
- 빌드: Node.js 24 이상

## 설치

```sh
npm install
npm run build
```

Zotero › 도구 › 플러그인 › 톱니바퀴 › **파일에서 플러그인 설치**에서 `.scaffold/build/zotero-claude-assist.xpi`를 고릅니다. 다시 빌드한 뒤에도 같은 방법으로 덮어 설치하고 Zotero를 재시작합니다.

### 첫 설정

Zotero › 설정 › **Claude Assist**:

1. **Claude CLI 연결 테스트**: `claude` 경로·버전, 짧은 응답(`PONG`), 사용할 수 있는 모델 목록이 나오면 됩니다. 처음 실행할 때 macOS 키체인 접근 허용 창이 뜰 수 있습니다. 경로를 못 찾으면 `claude 경로`에 직접 입력합니다 (`which claude`).
2. **Gemini**: AI Studio API 키를 입력하고 **Gemini 연결 테스트**.

## 사용법

### 문맥 번역

PDF에서 텍스트를 선택하면 나오는 팝업의 **문맥 번역** 버튼을 누르거나, 팝업이 떠 있을 때 `Ctrl+Shift+T`를 누릅니다. 같은 페이지의 앞뒤 문장(기본 2개)을 함께 보내 문맥에 맞게 번역합니다. 앞뒤 문장을 찾지 못하면 선택한 부분만 번역하고 **문맥 미포함**을 표시합니다.

### 컨텍스트 노트

항목(또는 그 PDF)을 우클릭 › **Claude 컨텍스트 노트 생성**. 노트가 이미 있으면 메뉴가 **재생성**으로 바뀌고, 덮어쓰기 전에 확인합니다. PDF 리더를 열지 않아도 됩니다. 메모 질문이나 채팅을 처음 쓸 때 노트가 없으면 자동으로 먼저 만듭니다. 노트는 직접 고쳐도 되고, 이후 답변은 고친 내용을 기준으로 합니다.

### 메모 질문

1. 하이라이트·밑줄·영역(이미지) 주석의 코멘트에 한 줄씩 `@claude 질문`을 적습니다. 한 코멘트에 여러 줄이면 각각 별개의 질문입니다.
2. PDF 툴바의 **Claude · n** 버튼으로 채팅 창을 열고 아래쪽 **답변 생성**을 누르거나(채팅 답변을 쓰는 중에는 꺼짐), 채팅에 `/memos`를 입력합니다. 사이드바 **Claude (메모 질문·채팅)** 섹션의 버튼도 같습니다.
3. 답이 도착하는 대로 질문 노트에 덧붙이고 그 줄을 `@claude ✓ 질문`으로 바꿉니다. 실패한 질문은 `@claude` 그대로 남아, 다시 실행하면 재시도됩니다.
4. 다시 묻고 싶으면 `✓`를 지웁니다. 새 항목으로 기록되고 `(재질문)`이 붙습니다.

질문 노트의 각 항목은 하이라이트 인용(클릭하면 PDF 위치로 이동) 또는 그림 → 질문 → 답변 → `p.쪽 · 날짜 · 모델 · ann:주석키#줄` 순입니다. 하이라이트에 수식이 있으면 답변 첫머리에 LaTeX로 복원해 보여줍니다. 처리 중에는 열려 있는 질문 노트 편집기가 읽기 전용이 됩니다(입력 중이던 글자를 지키기 위해).

### 채팅

PDF 툴바의 **Claude** 버튼을 누르면 그 논문의 채팅 창이 열립니다(사이드바에도 같은 대화가 있습니다). 위에서부터 논문 제목, **컨텍스트 노트** 링크와 응답 모델, 메모 질문 처리 결과와 **질문 노트 열기**, 대화, 대기 중인 메모 질문(쪽 목록)과 **답변 생성**, 입력칸 순입니다.

- 첫 질문 때 논문 정보, 컨텍스트 노트, 섹션 목록, 기존 질의응답을 함께 보냅니다. 필요하면 모델이 섹션 원문 파일을 읽습니다(그 폴더 밖의 파일은 읽을 수 없게 막혀 있습니다).
- 답변 속 위치 태그(`[Sec 3.2, p.4]`)는 작은 `p.4` 표시로 바뀌고, 답변 아래 **근거** 줄에 인용한 쪽이 모입니다. 누르면 PDF의 그 쪽으로 이동합니다.
- 답변마다 **질문 노트에 저장**(`전역 질문` 항목). 저장하면 `✓ 질문 노트에 저장됨`으로 바뀝니다. 채팅 화면의 수식은 `$…$` 텍스트로 보이고, 질문 노트에서는 렌더링됩니다.
- **중지**, **새 대화**. 15분 동안 쓰지 않으면 프로세스를 끄고, 다음 질문 때 같은 대화를 이어갑니다. 대화 기록은 Zotero를 재시작해도 남습니다.

## 프롬프트 수정

설정의 **프롬프트 폴더 열기**(기본: `~/Zotero/zotero-claude-assist/prompts/`)에서 Markdown 파일을 고치면 다시 빌드하지 않아도 적용됩니다.

| 파일                                         | 쓰는 곳       | 적용 시점                            |
| -------------------------------------------- | ------------- | ------------------------------------ |
| `translate.md`                               | 문맥 번역     | 다음 번역부터                        |
| `context-note.md` (+ `humanize-korean/*.md`) | 컨텍스트 노트 | 다음 생성부터                        |
| `memo-batch.md` (+ `humanize-digest.md`)     | 메모 질문     | 다음 실행부터                        |
| `sidebar-chat.md` (+ `humanize-digest.md`)   | 채팅          | 다음 메시지부터 (진행 중인 대화에도) |

플러그인을 업데이트할 때 기본 프롬프트가 바뀌었으면, **직접 고치지 않은 파일만** 새 기본본으로 교체합니다. 고친 파일은 그대로 둡니다. 컨텍스트 노트의 메타 줄에 `프롬프트 context-note v1.1`처럼 생성에 쓴 버전이 남습니다.

## 데이터 위치

Zotero 데이터 디렉터리(`~/Zotero`) 아래 `zotero-claude-assist/`:

| 경로                                        | 내용                                 |
| ------------------------------------------- | ------------------------------------ |
| `prompts/`                                  | 편집 가능한 프롬프트                 |
| `chats/<라이브러리>-<항목키>.json`          | 채팅 기록과 세션 ID                  |
| `runs/oneshot/`                             | 단발 호출의 작업 폴더                |
| `runs/chat-<라이브러리>-<항목키>/sections/` | 채팅용 섹션 원문 파일                |
| `logs/activity.jsonl`                       | 활동 로그(설정 › **로그 폴더 열기**) |

활동 로그에는 호출마다 시간, 기능, 모델, 소요 시간, 성공 여부가 남습니다. 논문 내용, 프롬프트, 답변은 기록하지 않습니다. 실패한 호출은 CLI·API가 낸 오류 메시지 앞부분(최대 300자)도 남습니다. 1MB를 넘으면 `activity.1.jsonl`로 넘어갑니다. Claude Code도 대화마다 `~/.claude/projects/` 아래에 세션 기록을 남깁니다(채팅은 논문마다 한 폴더).

## 운영 메모 (`context.md` §16)

- Gemini 무료 티어 요청은 Google 제품 개선에 쓰일 수 있습니다. 학회 리뷰 원고처럼 기밀 유지 의무가 있는 문서에서는 문맥 번역을 쓰지 마세요. Claude 쪽(Team)은 상업 약관이 적용됩니다.
- Team 시트는 연구실 조직 계정이므로 조직의 정책과 사용량 집계가 적용됩니다.
- 채팅과 메모 질문은 같은 Claude 구독 사용량을 쓰며, 다른 Claude Code 작업과도 한도를 공유합니다.

## 문제 해결

| 증상                               | 할 일                                                                    |
| ---------------------------------- | ------------------------------------------------------------------------ |
| "claude CLI를 찾지 못했습니다"     | 설정에 `claude` 경로 입력 (`which claude`)                               |
| "Claude 로그인이 필요합니다"       | 터미널에서 `claude` 실행 → `/login`                                      |
| "사용량 한도에 도달했습니다"       | 메시지의 재설정 시각 이후 다시 시도. 실패한 메모는 `@claude` 그대로 남음 |
| "설정한 모델을 사용할 수 없습니다" | 연결 테스트의 모델 목록에서 이름 확인                                    |
| 타임아웃                           | 설정에서 타임아웃을 늘림                                                 |
| 번역이 "문맥 미포함"               | 텍스트 레이어가 특이한 PDF. 선택 영역만 번역됨                           |
| "텍스트 레이어가 없는 스캔 PDF"    | 지원하지 않음(OCR 범위 밖)                                               |
| 그 밖의 오류                       | 활동 로그와 도움말 › 디버그 출력 기록(`[Claude Assist]`)을 확인          |

## 개발

```sh
npm run build        # 프롬프트 동기화 + 빌드 + 타입 검사
npm run test:unit    # 순수 로직 단위 테스트 (Node)
npx zotero-plugin test               # Zotero 안 통합 테스트 (임시 프로필, .env에 Zotero 경로)
ZCA_E2E=1 npx zotero-plugin test     # 실제 Claude 호출 포함 (Haiku, 구독 사용량 소모)
npm start            # 개발용 프로필로 Zotero 실행 (.env에 프로필 경로)
```

- 소스: `src/llm`(CLI·Gemini), `src/pdf`(텍스트·위치·그림·섹션), `src/notes`(노트 HTML·컨텍스트 노트·질문 노트), `src/memo`, `src/chat`, `src/features`(UI)
- 프롬프트 원본은 `prompts/`, `vendor/humanize-korean/`. 빌드 때 `addon/content/prompts/`로 복사됩니다.
- Zotero 리더의 비공개 내부 구조(문자 데이터, 선택 영역)와 노트 편집기 내부에 의존하는 부분이 있습니다. Zotero 업데이트 후에는 `npx zotero-plugin test`를 먼저 돌려 보세요.
